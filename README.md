# 🔒 Лабораторна робота №1 з Криптографії (Web-додаток)


## 📌 Опис проєкту
Цей проєкт — повноцінний вебдодаток, розроблений для демонстрації базових криптографічних алгоритмів. Додаток має сучасний графічний інтерфейс та вбудовану систему авторизації з криптографічним захистом даних користувачів.

## 🚀 Реалізований функціонал

Згідно з вимогами до лабораторної роботи, у додатку реалізовано:
- [x] **Система безпеки:** Реєстрація та вхід користувачів. Паролі не зберігаються у відкритому вигляді, а надійно хешуються (алгоритм PBKDF2/SHA256).
- [x] **Шифр Цезаря:** Шифрування та дешифрування тексту із заданим зсувом (підтримується український та англійський алфавіти зі збереженням регістру).
- [x] **Частотний криптоаналіз:** Автоматичний підрахунок частоти появи літер у тексті (у відсотках).
- [x] **Шифри перестановки:**
  - *Вертикальна перестановка* за ключовим словом.
  - *Горизонтальна перестановка*.
  - *Комбінована (подвійна) перестановка* (послідовне застосування двох різних ключів для максимальної надійності).

## 🛠 Технології
- **Backend:** Python 3, Flask, Werkzeug Security
- **Frontend:** HTML5, Bootstrap 5 (Dark UI Theme)
- **База даних:** SQLite (для зберігання хешів паролів)
